# The Long Argument

Briefings on 26 foundational works of Western literature and philosophy, from Gilgamesh to Joyce.
Not a reading list — an argument that runs across 4,000 years and never resolves.

**Three ways in:** by argument (eight threads), by date (the timeline), or by form
(scripture & myth, epic, drama, philosophy, confession, the essay, the novel).

## Deploy

Everything is static. Copy the contents of this folder to a repo, then
**Settings → Pages → Deploy from a branch → `main` / root**.

`index.html` is entirely self-contained — fonts are embedded, there are no external
requests, no tracking, and no server. It works offline and by double-clicking the file.

`sw.js`, `manifest.webmanifest` and `icon.svg` are optional; they make it installable
to a phone home screen. Registration is opt-in — see the note at the bottom of `index.html`.
